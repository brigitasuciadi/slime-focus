
# Slime Focus 🩵

A simple and aesthetic Pomodoro desktop timer built with Electron, HTML, CSS, and Vanilla JavaScript.

## About

Slime Focus is a lightweight desktop application designed to help users manage their study and work sessions using the Pomodoro technique.

It features a cute slime mascot and a soft baby-blue pixel-inspired interface.

## Features

- Pomodoro timer (25 minutes)
- Short break (5 minutes)
- Long break (15 minutes)
- Start, Pause, Resume, and Reset controls
- Customizable timer duration
- Animated slime mascot
- Compact desktop window

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Electron
- Electron Builder

## Installation

1. Download or clone this repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the application:

   ```bash
   npm start
   ```
